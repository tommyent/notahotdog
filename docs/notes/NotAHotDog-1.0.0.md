The first public release.

- **Hide menu bar icons.** Choose Arrange Icons, ⌘-drag the icons you don't need to the left of Done, then click Done.
- **Get them back with a click.** Click the hot dog to see the hidden icons, then click one to use it as usual.
- **Three styles.** Shelf (a row under the menu bar), Tray (a small grid) or Index (a list with each app's name).
- **Launch at Login** and **Check for Updates…** in the right-click menu.

For Apple silicon Macs on macOS 27.3 or later (in beta as of November 2026). To check the download, run `shasum -a 256 -c NotAHotDog-1.0.0.dmg.sha256` in the folder that holds both files.
